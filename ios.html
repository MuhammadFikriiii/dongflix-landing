Pasang Scarlet

Buka situs Scarlet melalui Safari di iPhone, pilih Direct Install, lalu selesaikan pemasangannya.

Izinkan pengembang

Jika diminta, buka Pengaturan › Umum › VPN & Manajemen Perangkat, pilih profil pengembang Scarlet, lalu izinkan.

Import file ke Scarlet

File IPA yang sudah diunduh tersimpan di aplikasi Files. Bagikan file tersebut ke Scarlet, atau buka Scarlet lalu gunakan menu impor.

4

Buka menggunakan Scarlet

Dari Files, bagikan file IPA ke Scarlet. Jika Scarlet tidak muncul, buka Scarlet lalu gunakan menu impor dan pilih file tersebut.

5

Instal DongFlix

Tekan Install di Scarlet dan tunggu ikon DongFlix muncul di layar utama. Jangan menghapus Scarlet selama DongFlix masih digunakan.
